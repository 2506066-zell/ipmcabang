Langkah Install

Android (Chrome/Edge)
  1. Tap tombol Install Aplikasi.
  2. Konfirmasi instalasi dari browser.
  3. Ikon aplikasi muncul di layar utama.
iPhone/iPad (Safari)
  1. Tap tombol Share di Safari.
  2. Pilih Add to Home Screen.
  3. Tap Add.
