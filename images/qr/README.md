# QR Install PWA (Sosial Media)

Aset ini untuk diposting di sosial media agar calon user bisa scan dan langsung buka aplikasi.

## File Utama

- `pwa-install-ipmcabang-1200.png`  
  QR standar untuk `https://ipmcabang.vercel.app/`
- `pwa-install-ipmcabang-1600-dark.png`  
  QR high-res tema gelap untuk `https://ipmcabang.vercel.app/`
- `pwa-install-ipmcabangpnw-1200.png`  
  QR standar untuk `https://ipmcabangpnw.vercel.app/`
- `pwa-install-ipmcabangpnw-1600-dark.png`  
  QR high-res tema gelap untuk `https://ipmcabangpnw.vercel.app/`

## File QR Install (Direkomendasikan)

QR ini menuju halaman install khusus (`/install`) agar user langsung fokus ke proses pemasangan aplikasi.

- `pwa-install-direct-ipmcabang-1200.png`
- `pwa-install-direct-ipmcabang-1600-dark.png`
- `pwa-install-direct-ipmcabangpnw-1200.png`
- `pwa-install-direct-ipmcabangpnw-1600-dark.png`

## Template Poster

- `pwa-install-poster.html`  
  Template poster 1:1. Buka file ini di browser, lalu screenshot/export untuk upload Instagram feed.

## Rekomendasi Posting

- Feed IG/FB: pakai file `*-1600-dark.png` atau template poster.
- Story: gunakan poster, lalu tambahkan CTA: `Scan QR untuk install aplikasi`.
- Tambahkan caption:
  - `Scan QR ini untuk buka aplikasi PC IPM Panawuan.`
  - `Setelah terbuka, pilih Add to Home Screen agar jadi seperti aplikasi.`
